# SpiritHub Frontend

SpiritHub Frontend is a React + TypeScript + Vite application for creator communities and collaboration.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Use `scripts/deploy.sh` for manual hotfix deployment and `scripts/rollback.sh` for recovery. Production deployment is automated through GitHub Actions.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
